# Studium Routine

Sistema web desenvolvido para a organização de rotinas, horários de estudo e eventos escolares. O projeto tem como objetivo centralizar o planejamento diário dos estudantes, oferecendo uma interface simples, intuitiva e responsiva para ajudar na gestão de prazos e compromissos acadêmicos com maior autonomia e tranquilidade.

## 🚀 Tecnologias Utilizadas
- **HTML5:** Utilizado para a estruturação semântica e lógica das páginas da aplicação.
- **CSS3:** Utilizado para a estilização visual, design responsivo e identidade estética do sistema.
